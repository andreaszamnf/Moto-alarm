# Συναγερμός μηχανής με GPS και 4G (DIY)

Συναγερμός και εντοπισμός για μοτοσυκλέτα, φτιαγμένος από κοινά κομμάτια: μια πλακέτα με 4G και GPS κρυμμένη στη μηχανή, ένας δωρεάν server στο Cloudflare και μια εφαρμογή στο κινητό (στα ελληνικά). Δεν έχει μηνιαία συνδρομή εκτός από την κάρτα SIM.

*A DIY motorcycle alarm and GPS tracker: LilyGO T-SIM7600E board, Cloudflare Worker, Greek phone app (PWA). The guide below is in Greek.*

## Τι κάνει

- **Συναγερμός:** όταν είναι οπλισμένος και κάποιος κουνήσει τη μηχανή, σου έρχεται ειδοποίηση σε 4–5 δευτερόλεπτα. Με το Pushover ακούγεται και στο αθόρυβο. Ένα απλό ακούμπημα δεν τον χτυπάει: η πλακέτα μετράει 3 δευτερόλεπτα πριν αποφασίσει.
- **Εντοπισμός:** σε συναγερμό στέλνει θέση GPS κάθε 30 δευτερόλεπτα, και η εφαρμογή δείχνει τη διαδρομή στον χάρτη. Χωρίς GPS (γκαράζ, φορτηγάκι) βρίσκει περίπου θέση από τα Wi-Fi γύρω της.
- **Οδήγηση:** όταν είναι αφοπλισμένος, η εφαρμογή δείχνει ζωντανά ταχύτητα και διαδρομή, και κρατάει ιστορικό διαδρομών.
- **Ατύχημα:** αν η μηχανή πέσει στην οδήγηση και δεν πατήσεις «Είμαι καλά» σε 90 δευτερόλεπτα, στέλνει SMS με το σημείο σε άνθρωπο που διαλέγεις. Δεν καλεί ποτέ μόνη της το 112.
- **Και ακόμα:** βιβλίο σέρβις, σύνδεσμος ζωντανής θέσης για φίλους, φάκελος κλοπής για την αστυνομία, λειτουργία «δανεική / συνεργείο», πρωινή σύνοψη, αυτόματη όπλιση με πρόγραμμα, ενημέρωση της πλακέτας από απόσταση.
- **Δίκτυο:** στέλνει από Wi-Fi όπου ξέρει δίκτυο (σπίτι, πάρκινγκ) και από 4G παντού αλλού. Με τη μπαταρία της μόνο κρατάει μερικές μέρες, γιατί κοιμάται σχεδόν πάντα. Με ρεύμα από τη μηχανή δουλεύει συνέχεια.

> **Προσοχή.** Είναι ερασιτεχνική κατασκευή, χωρίς καμία εγγύηση. Δεν αντικαθιστά πιστοποιημένο συναγερμό, κλειδαριά ή το 112. Χρησιμοποίησέ το μόνο στη δική σου μηχανή.

## Τι χρειάζεσαι

**Υλικά**

| Τι | Σημειώσεις |
|---|---|
| LilyGO **T-SIM7600E-L1C** | ESP32 με modem 4G (SIM7600E) και GPS, θήκη για μπαταρία 18650. Το «E» είναι για Ευρώπη· αλλού θέλει άλλη έκδοση (π.χ. SIM7600A/G). Έρχεται με κεραίες 4G και GPS. |
| Αισθητήρας κίνησης **ADXL345** (πλακετάκι GY-291) | Πέντε καλώδια προς την πλακέτα. |
| Μπαταρία **18650** | Καλής ποιότητας, για εφεδρεία. |
| Κάρτα **nano SIM** με δεδομένα και SMS | Αρκούν λίγα MB τον μήνα. Στην Ελλάδα π.χ. κάρτες IoT. Βγάλε το PIN από ένα κινητό πριν τη βάλεις. |
| Καλώδια, κολλητήρι, καλάι, πολύμετρο | Για τις 5 κολλήσεις του αισθητήρα. |
| Θερμοσυστελλόμενο ~50 mm ή μικρό αδιάβροχο κουτί, silica gel | Για να μπει κάτω από τη σέλα. |
| *Προαιρετικά:* αδιάβροχος μετατροπέας 12 V → 5 V/3 A με έξοδο USB-A, ασφάλεια 2–3 A, καλώδιο USB-A → USB-C | Για μόνιμο ρεύμα από τη μηχανή. Η πλακέτα **δεν** φορτίζει με καλώδιο USB-C → USB-C. |

**Λογαριασμοί**

- **Cloudflare** (δωρεάν): εκεί τρέχει ο server και η βάση.
- **Pushover** (προαιρετικό, εφάπαξ λίγα ευρώ): ο δυνατός συναγερμός που ακούγεται και στο αθόρυβο.
- **Google Cloud** (προαιρετικό): κλειδί για θέση από Wi-Fi. Χωρίς αυτό χρησιμοποιείται η δωρεάν beaconDB.

**Στον υπολογιστή:** [Node.js](https://nodejs.org) 20 ή νεότερο, [Git](https://git-scm.com) και [arduino-cli](https://arduino.github.io/arduino-cli/). Όλες οι εντολές παρακάτω τρέχουν από τον φάκελο του κώδικα.

## 1. Κατέβασε τον κώδικα

```
git clone <διεύθυνση αυτού του αποθετηρίου>
cd Moto-alarm
npm install
```

## 2. Ο server στο Cloudflare

Μία φορά, από τον φάκελο `server/`:

```
cd server
npx wrangler login
npx wrangler d1 create moto-alarm
npx wrangler kv namespace create FIRMWARE
```

Γράψε στο `server/wrangler.toml` το `database_id` και το `id` που τύπωσαν οι δύο τελευταίες εντολές. Μετά:

```
npx wrangler d1 execute moto-alarm --remote --file=schema.sql
npx wrangler deploy
```

Το `deploy` τυπώνει τη διεύθυνσή σου, π.χ. `https://moto-alarm.<το-όνομά-σου>.workers.dev`. Βάλ' τη στο `PUBLIC_ORIGIN` και στο `VAPID_SUBJECT` του `wrangler.toml`.

Τα μυστικά (κλειδιά), από τον αρχικό φάκελο:

```
cd ..
node tools/make-secrets.mjs .secrets/secrets.json .secrets/device-key.txt
cd server
npx wrangler secret bulk ../.secrets/secrets.json
cd ..
node tools/set-password.mjs
```

Σβήσε μετά το `.secrets/secrets.json`. Το `set-password` σε ρωτάει τον κωδικό της εφαρμογής, που θέλει λατινικούς χαρακτήρες. Τέλος, `npx wrangler deploy` ξανά από το `server/`.

Ο φάκελος `.secrets/` κρατάει τα κλειδιά σου και δεν μπαίνει ποτέ στο git. Κράτα αντίγραφό του κάπου ασφαλές.

## 3. Οι κολλήσεις

Πέντε καλώδια από τον αισθητήρα στις τρύπες της πλακέτας. Οι τρύπες είναι στη δεξιά σειρά της μπροστινής πλευράς και μετράνε από πάνω, με το ESP32 προς τα πάνω.

| ADXL345 (GY-291) | Πλακέτα |
|---|---|
| VCC | 3V3 (3η τρύπα) |
| GND | GND (4η τρύπα) |
| SCL | IO22 (5η τρύπα) |
| SDA | IO21 (6η τρύπα) |
| INT1 | IO39 (11η τρύπα) |
| CS, INT2, SDO | χωρίς καλώδιο |

Κράτα τα πέντε καλώδια κοντά, λίγα εκατοστά, και στρίψε τα χαλαρά μεταξύ τους: έτσι πιάνουν λιγότερες παρεμβολές από την κεραία 4G. Προαιρετικά, ένας κεραμικός πυκνωτής 100 nF ανάμεσα στο VCC και το GND, κολλημένος πάνω στον αισθητήρα, φιλτράρει τις μικρές αναταράξεις στο ρεύμα του.

Βήμα-βήμα οδηγίες με σχέδια και έλεγχο με πολύμετρο: άνοιξε το [`docs/soldering.html`](docs/soldering.html) σε browser.

## 4. Το πρόγραμμα της πλακέτας

Μία φορά:

```
arduino-cli core install esp32:esp32@2.0.17 --additional-urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
arduino-cli lib install ArduinoJson@7.2.1
node tools/make-firmware-signing-key.mjs
```

Το τελευταίο φτιάχνει το δικό σου κλειδί για τις ενημερώσεις από απόσταση: η πλακέτα δέχεται μόνο προγράμματα υπογεγραμμένα με αυτό. Κράτα το `.secrets/firmware-signing.pem`. Αν χαθεί, η επόμενη ενημέρωση θέλει καλώδιο USB.

Μετά:

```
node tools/set-wifi.mjs
node tools/make-firmware-secrets.mjs
arduino-cli compile --fqbn esp32:esp32:esp32:PartitionScheme=min_spiffs --output-dir firmware/build firmware/moto-alarm
arduino-cli board list
arduino-cli upload -p COM5 --fqbn esp32:esp32:esp32:PartitionScheme=min_spiffs --input-dir firmware/build firmware/moto-alarm
```

- **`set-wifi`** (προαιρετικό) βάζει το Wi-Fi του σπιτιού μέσα στο πρόγραμμα. Άλλα δίκτυα προστίθενται αργότερα από την εφαρμογή.
- **`make-firmware-secrets`** γράφει τη διεύθυνση του server και το κλειδί της συσκευής. Αν η κάρτα θέλει APN, γράψ' το στο τέλος της εντολής.
- **`board list`** δείχνει σε ποια θύρα (COM) είναι η πλακέτα, για να τη βάλεις στη θέση του `COM5`.
- **Το `PartitionScheme=min_spiffs` πρέπει να μπει από το πρώτο ανέβασμα με USB.** Χωρίς αυτό δεν γίνονται αργότερα ενημερώσεις από απόσταση.
- **Στην πρώτη εκκίνηση** το LED μένει αναμμένο μέχρι να φτάσει η πρώτη αναφορά στον server. Για να δεις τι κάνει: `arduino-cli monitor -p COM5 -c baudrate=115200`.

## 5. Η εφαρμογή στο κινητό

1. Άνοιξε τη διεύθυνση του server στο κινητό και πρόσθεσέ τη στην αρχική οθόνη. Στο iPhone: Safari → Κοινοποίηση → «Προσθήκη στην οθόνη Αφετηρίας». Στο Android: Chrome → «Εγκατάσταση εφαρμογής».
2. Συνδέσου με τον κωδικό σου και πάτα «Ενεργοποίηση ειδοποιήσεων». Στο iPhone οι ειδοποιήσεις δουλεύουν μόνο από την εφαρμογή της αρχικής οθόνης.
3. Πέρασε από τις Ρυθμίσεις:
   - **Δυνατός συναγερμός:** κλειδιά Pushover.
   - **Wi-Fi της πλακέτας:** δίκτυα όπου παρκάρεις.
   - **Συναγερμός:** ευαισθησία.
   - **Αυτόματη όπλιση.**
   - **Ατύχημα:** επαφή έκτακτης ανάγκης, και εκεί η «Δοκιμή».
   - **Κατανάλωση:** «Χαμηλή κατανάλωση» για όταν η μηχανή μένει μέρες ακίνητη: λιγότερες αναφορές και το modem κλειστό στη στάθμευση, με λίγο πιο αργό συναγερμό από 4G.

## 6. Πάνω στη μηχανή

- **Θέση:** κάτω από τη σέλα, με την κεραία GPS να «βλέπει» προς τα πάνω χωρίς μέταλλο από πάνω της και την κεραία 4G μακριά από μεγάλα μέταλλα.
- **Κεραία 4G και αισθητήρας:** κράτα την κεραία 4G και το καλώδιό της όσο πιο μακριά χωράει από τον αισθητήρα. Όταν το modem εκπέμπει, ιδίως με αδύναμο σήμα, μπορεί να ξεγελάσει τον αισθητήρα και να βγάλει ψεύτικο συναγερμό. Γι' αυτό, δίπλα σε γνωστό Wi-Fi, το πρόγραμμα κλείνει το modem.
- **Στερέωση:** η πλακέτα πρέπει να είναι σταθερή και να μη γλιστράει, γιατί ο συναγερμός και η ανίχνευση πτώσης κοιτάνε την κλίση της.
- **Προστασία από νερό:** θερμοσυστελλόμενο με τις άκρες κλεισμένες με θερμόκολλα ή σιλικόνη και silica gel μέσα. Ζέσταμα μόνο με πιστόλι θερμού αέρα, ποτέ με φλόγα, γιατί μέσα είναι η μπαταρία.
- **Ρεύμα:**
  - Με τη μπαταρία 18650 μόνο, κρατάει μερικές μέρες.
  - Για μόνιμη λειτουργία βάλε μετατροπέα 12 V → 5 V από τη μπαταρία της μηχανής, με ασφάλεια κοντά στον πόλο +. Καλύτερα να τον βάλει ηλεκτρολόγος μοτοσυκλετών.
  - Η 18650 μένει ως εφεδρεία, και αν κοπεί το ρεύμα της μηχανής η εφαρμογή σού το λέει.
- **Δοκιμή πριν το εμπιστευτείς:**
  1. Όπλισε και κούνησε τη μηχανή: πρέπει να έρθει συναγερμός.
  2. Αφόπλισε και κάνε μια βόλτα: η εφαρμογή πρέπει να δείχνει «Οδηγείς τώρα».
  3. Κάνε τη «Δοκιμή» του «Ατυχήματος» από την εφαρμογή.

## Ενημέρωση της πλακέτας από απόσταση

Αφού κλειστεί η πλακέτα, νέα προγράμματα μπαίνουν χωρίς καλώδιο:

1. Αύξησε το `FIRMWARE_VERSION` στο `firmware/moto-alarm/config.h`.
2. Μεταγλώττισε όπως πριν.
3. Τρέξε `node tools/publish-firmware.mjs`.

Η πλακέτα το κατεβάζει σε ήσυχη ώρα (όχι σε συναγερμό ή οδήγηση, με μπαταρία από 30% και πάνω) και ελέγχει την υπογραφή. Αν το νέο πρόγραμμα δεν μπορέσει να μιλήσει με τον server, γυρίζει μόνη της στο παλιό.

## Δοκιμή στον υπολογιστή, χωρίς πλακέτα

```
npm run dev
npm test
```

Η εφαρμογή ανοίγει στο http://localhost:5173 (κωδικός `dev`) και έχει προσομοιωτή συσκευής στο http://localhost:5173/dev/sim.

## Πώς δουλεύει

- **Ύπνος:** η πλακέτα κοιμάται. Ξυπνάει με κίνηση, κάθε 15 λεπτά για ένα σύντομο «είμαι εδώ» και κάθε 6 ώρες για θέση GPS.
- **Ποιος αποφασίζει:** ο server ξέρει αν ο συναγερμός είναι οπλισμένος, οπότε αποφασίζει αν η κίνηση είναι κλοπή ή εσύ που ξεκινάς. Έτσι ο οπλισμός από το κινητό ισχύει ακόμα κι αν η μηχανή δεν έχει σήμα εκείνη τη στιγμή.
- **Κίνηση ή ακούμπημα:** μετά από ένα ξύπνημα μετράει 3 δευτερόλεπτα. Κίνηση είναι κούνημα που κρατάει ή αλλαγή στην κλίση. Τρία ακουμπήματα μέσα σε 2 λεπτά μετράνε επίσης ως κίνηση.
- **Δίκτυο:** δίπλα σε γνωστό Wi-Fi στέλνει από εκεί και κλείνει εντελώς το modem, γιατί σε αδύναμο 4G η εκπομπή του μπορεί να ξεγελάσει τον αισθητήρα. Αλλού το modem μένει συνδεδεμένο σε χαμηλή κατανάλωση, ώστε ο συναγερμός να φεύγει σε λίγα δευτερόλεπτα.
- **Ατύχημα:** όσο οδηγείς, η πλακέτα μαθαίνει πώς στέκεται όρθια η μηχανή. Πτώση είναι όταν, λίγο αφού πήγαινες πάνω από 20 χλμ/ώ, η μηχανή απέχει πάνω από 50° από την όρθια θέση και μένει ακίνητη 10 δευτερόλεπτα. Πρέπει να πέσει μέσα σε 15 δευτερόλεπτα αφού σταμάτησε. Αν η πλακέτα γυρίσει μέσα στη θέση της ενώ η μηχανή στέκεται, ξαναμαθαίνει την όρθια θέση στην επόμενη διαδρομή.
- **Δεδομένα:** όλα μένουν στον δικό σου λογαριασμό Cloudflare. Οι θέσεις κρατιούνται 90 μέρες, και οι σύνδεσμοι κοινοποίησης λήγουν μόνοι τους.

Τα αρχεία:

| Φάκελος | Τι είναι |
|---|---|
| `server/` | Ο server (Cloudflare Worker με βάση D1). Η λογική είναι στο `server/src/`. |
| `app/` | Η εφαρμογή του κινητού (PWA). |
| `firmware/moto-alarm/` | Το πρόγραμμα της πλακέτας (Arduino, ESP32). |
| `tools/` | Εργαλεία για κλειδιά, Wi-Fi, ενημερώσεις και τοπικό server δοκιμών. |
| `docs/` | Οδηγίες κολλήσεων. |

## Για άλλη μηχανή

- **Όνομα εφαρμογής:** γράφει «Hornet 750», γιατί φτιάχτηκε για ένα Honda CB750 Hornet. Άλλαξέ το στο `app/index.html` και στο `app/manifest.webmanifest`.
- **Βιβλίο σέρβις:** οι αρχικές προτάσεις είναι από το πρόγραμμα της Honda για το Hornet 750 (`server/src/service.js`). Αλλάζουν και από την εφαρμογή, στις «Προτάσεις».
- **Γλώσσα και ώρα:** η εφαρμογή και οι ειδοποιήσεις είναι στα ελληνικά. Η ώρα είναι η ώρα Ελλάδας (`TIME_ZONE` στο `server/src/logic.js`).
- **Ευαισθησία:** τα όρια του αισθητήρα είναι στο `firmware/moto-alarm/accel.cpp` και του ατυχήματος στο `config.h`. Ρυθμίζονται πάνω στη μηχανή.

## Γνωστά όρια

- **Ανίχνευση πτώσης:** δεν έχει δοκιμαστεί σε αληθινή πτώση. Δουλεύει μόνο όσο οδηγείς αφοπλισμένος.
- **Πιστοποιητικό του server:** η πλακέτα δεν το ελέγχει ακόμα, ούτε από Wi-Fi ούτε από 4G. Η σύνδεση είναι κρυπτογραφημένη, αλλά κάποιος που ελέγχει το δίκτυο (π.χ. ένα Wi-Fi) θα μπορούσε να παραστήσει τον server: να δει τις αναφορές και να στείλει ψεύτικες εντολές. Νέο πρόγραμμα δεν μπορεί να βάλει, γιατί οι ενημερώσεις είναι υπογεγραμμένες. Το κλειδί της συσκευής μπορεί μόνο να στέλνει αναφορές. Ο έλεγχος του πιστοποιητικού είναι στα επόμενα βήματα.
- **SMS στα ελληνικά:** στέλνονται ως UCS-2, οπότε ένα SMS χωράει 70 χαρακτήρες.
